# MetaServer Client

Flutter client for mobile and web account screens.

## Firebase Values

Firebase configuration is generated by FlutterFire CLI into
`lib/firebase_options.dart` and `android/app/google-services.json`.

Regenerate Firebase config:

```powershell
dart pub global activate flutterfire_cli
dart pub global run flutterfire_cli:flutterfire configure `
  --project=metaserver-6dc49 `
  --platforms=android,web `
  --android-package-name=com.example.metaserver_client `
  --android-out=android/app/google-services.json `
  --out=lib/firebase_options.dart `
  --yes `
  --overwrite-firebase-options
```

Run on the Android emulator:

```powershell
flutter run -d emulator-5554
```

Android defaults to `http://10.0.2.2:8000/api/v1`, which reaches the local
backend running on the host PC. Use `--dart-define=API_BASE_URL=...` only when
you need to point the app at a different API server.

## Screens

```text
/sign-in
/sign-up
/forgot-password
/change-password
/account
```

The client uses Firebase Auth for credentials and sends Firebase ID tokens to the FastAPI backend.
